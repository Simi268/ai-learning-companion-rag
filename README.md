# AI Learning Companion

An AI-powered Learning Companion built with **Streamlit, LangChain, ChromaDB, and Groq LLMs**.

This project combines:

* 📚 PDF Knowledge Retrieval
* 🧠 Semantic Memory
* 🔎 Vector Search
* 💬 Conversational AI
* ⚡ Hybrid RAG Architecture

Users can upload PDFs, ask questions, retrieve contextual information, and interact with an intelligent AI assistant using semantic search and memory retrieval.

---

# Features

* Upload and analyze PDFs
* Semantic memory storage
* Hybrid retrieval system
* Conversational AI interface
* ChromaDB vector database
* Streamlit professional UI
* Transformer-based embeddings
* Long-context memory handling
